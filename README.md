### About me

I’m **Abdullah Nuhrio**, a software engineer working with **ASP.NET Core and enterprise .NET architecture**. I focus on maintainable backend systems, modular designs, secure APIs, complex database integrations, and practical software engineering.

My approach combines thoughtful system design with hands-on implementation — from requirements and architecture to APIs, persistence, integrations, and deployment.

- **Architecture:** Clean Architecture, Modular Monolith, SOLID, CQRS, Repository and Unit of Work
- **Backend:** C#, ASP.NET Core, REST APIs, background processing and real-time features
- **Data:** Entity Framework Core, Dapper, ADO.NET, SQL Server and Oracle
- **Security:** Identity, authentication, RBAC and fine-grained permissions
- **Currently exploring:** Reusable enterprise foundations in .NET 10
